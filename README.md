# PrestaShop AddONs

Custom PrestaShop add-ons by Dong Solar Limited.

## Dong Solar Live Chat 1.1.50

Storefront live chat with a back-office inbox, visitor monitoring, editable lead
details, CSV export, page-visit history, browser notifications, working-hours
controls and optional OpenAI replies.

- [Feature description and setup](ADDON-DETAILS.txt)
- [Module source](donglivechat/)
- [Installable module ZIP](packages/donglivechat-v1.1.50.zip)

Upload the module ZIP through PrestaShop's Module Manager. The source declares
PrestaShop 9.0.0–9.9.9 compatibility; the project targets PrestaShop 9.0.2.
Upgrade existing installations in place and back up the database first.

The source and ZIP are preserved as supplied. Publication adds documentation;
it does not certify runtime compatibility or security.
